About Dijkstra's Algorithm

Dijkstra's Algorithm is a shortest-path algorithm used to find the minimum distance between nodes in a weighted graph.

It repeatedly selects the unvisited node with the smallest known distance and updates the distances of its neighboring nodes.

In this project, road weights represent distances. Traffic conditions can dynamically increase the effective road weight.

Time Complexity O(V²)
Space Complexity O(V)

How Dijkstra Works

1

Initialize

Set the starting node distance to zero and all other distances to infinity.

2

Select Minimum

Select the unvisited node with the smallest distance.

3

Relax Edges

Calculate whether traveling through the current node provides a shorter route.

4

Repeat

Continue until the destination is reached.

5

Build Path

Trace the previous nodes to construct the shortest path.
